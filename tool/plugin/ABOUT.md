# plugin

## Overview
Tooling to build, test, and deploy the flutter-intellij plugin.

## Interface & Configuration
- `pubspec.yaml`: Dart package specification.
- `CHANGELOG.md`: Change history for the plugin tool.
- `README.md`: Tool documentation.
- `plugin.iml`: IntelliJ module file.

## Subdirectories & Boundaries
- bin: [./bin/ABOUT.md](./bin/ABOUT.md) - Entry point for the plugin tool.
- lib: [./lib/ABOUT.md](./lib/ABOUT.md) - Core library implementing plugin generation, linting, building, and deployment commands.
- test: Tests for the plugin tool.
