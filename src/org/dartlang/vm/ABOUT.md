# org.dartlang.vm

## Overview
Groups plugin-owned packages related to the Dart Virtual Machine.

## Subdirectories & Boundaries
- `service`: [./service/ABOUT.md](./service/ABOUT.md) - Dart VM Service client implementation, including the VmService class and related listeners for interacting with a running Dart VM via JSON-RPC.

## Provenance and Licensing
- The VM Service client originated in the Dart `vm_service_drivers` project and is now maintained as part of the plugin.
- `LICENSE` and `readme.txt` retain the original licensing and provenance information.
