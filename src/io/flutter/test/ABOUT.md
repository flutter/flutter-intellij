# Flutter Test Converter

## Overview
Parses test runner events from Dart's `package:test` and translates them into IntelliJ test framework service messages.

The only class, [`DartTestEventsConverterZ`](DartTestEventsConverterZ.java), is a base class; the concrete converter used by Flutter test runs is [`FlutterTestEventsConverter`](../run/test/FlutterTestEventsConverter.java), which overrides `process(JsonArray)`.

## Interface
- `class DartTestEventsConverterZ`
- `DartTestEventsConverterZ(String testFrameworkName, TestConsoleProperties consoleProperties, DartUrlResolver urlResolver)`
- `protected boolean processServiceMessages(String text, Key outputType, ServiceMessageVisitor visitor)`
- `protected boolean process(JsonArray array)` - No-op hook (returns `false`) for subclasses.
- `protected void preprocessTestStart(Test test)`
- `protected boolean handleGroup(Group group)`
- `protected static class Item`
- `protected static class Test extends Item`
- `protected static class Group extends Item`
- `protected static class Suite extends Item`

## Invariants
- Parses test runner events in JSON format generated by Dart package:test. Lines that are not JSON are passed to the TeamCity service-message parser.
- If the output says `"json" is not an allowed value for option "reporter"`, a synthetic failed test asks the user to upgrade `package:test` to 0.12.9 or later.
- Groups, suites, and tests are tracked by integer IDs provided in the JSON events.
- Virtual tests are hidden from the UI if they pass, but reported if they fail (`shouldTestBeHiddenIfPassed`):
  - `loading …`/`compiling …` tests only when they have no parent group;
  - `(setUpAll)` only before any test in its group has finished;
  - `(tearDownAll)` only after at least one test in its group has finished.
- Duration of a test is calculated using the difference between testDone and testStart timestamps.
- Location hints use the `dart_location://` prefix, which is resolved by [`DartTestLocationProviderZ`](../run/test/DartTestLocationProviderZ.java).

## Side Effects
- Mutates internal state maps (myTestData, myGroupData, mySuiteData, myTestIdToTimestamp) as test events are processed.
- Emits IntelliJ test framework service messages to the provided ServiceMessageVisitor.
